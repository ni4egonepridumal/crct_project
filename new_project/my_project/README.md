### 1. Клонируем проект

```
git clone https://github.com/ni4egonepridumal/crct_project.git
```

### 2. Переходим в папку проекта из консоли vs coda или иной консоли

```
cd crct_project

//еще раз тут же 

cd new_project

//еще раз тут же

cd my_project
```

### 3. Устанавливаем зависимости

```
npm install
```

### 4. Запускаем проект

```
npm run dev
```
